# Exam-scoring docs

These guides describe the scoring code in `src/scoring/` (prepare / score / compile). They were written for a
standalone toolkit, so read them with these substitutions:

| in the docs | here |
|---|---|
| `python prepare_exam.py --config C` | `script/cli_prepare` (all workspaces) or `python src/scoring/prepare_exam.py --config C` |
| `python score_exams.py --config C ...` | `script/cli_score [--check]` (all workspaces) or `python src/scoring/score_exams.py --config C ...` |
| `python compile_ai_grades.py --config C` | `script/cli_compile C` |
| `python normalize_exam_pdfs.py ...` | `script/cli_normalize ...` |
| `workspaces/my_exam/` | `data/cli/<exam>/` (generated by `script/cli_build`) |
| `examples/minimal_exam`, `python -m unittest` | `tests/fixtures/minimal_exam`, `script/test` |
| `.env` in the workspace | one shared `benchmark/.env` (copy `.env.example`); `script/cli_score` loads it |

The demo runner and the shareable-archive builder of the original package are not included.
